# Seminar Demonstration Plan (5-7 Minutes)

## Demo Project
**Library Management System**

## Core Message
"Groq generates, Jev validates, humans govern."

## Step-by-Step Script

**1. Login & Dashboard (0:30)**
- *Action:* Log into the application. Show empty dashboard.
- *Script:* "Welcome to our AI-Native SDLC prototype. Today, we'll build a Library Management System. Notice I am logging in as a human governing this process."

**2. Create Project & Idea (0:30)**
- *Action:* Click 'New Project'. Enter idea: "A web app to track library books and user checkouts."
- *Script:* "We start with a simple natural language idea. No code yet."

**3. Generate Requirements (1:00)**
- *Action:* Click 'Generate Requirements'. Wait for Groq & Jev.
- *Script:* "The Requirement Agent (powered by Groq) is drafting a formal spec. Meanwhile, Jev is independently validating it for completeness."
- *Action:* Show Jev validation card on UI.
- *Script:* "Here we see Jev's validation score. The AI proposes, but I must approve."

**4. Edit/Reject and Regenerate (1:30)**
- *Action:* Click 'REJECT'. Add feedback: "Include a feature for late fees." Click 'REGENERATE'.
- *Script:* "I noticed it missed late fees. I'll reject it, add feedback, and regenerate. The AI updates the document."
- *Action:* Show version history (v1 vs v2). Click 'APPROVE'.
- *Script:* "Version 2 looks great. I approve, locking this as context for the next stage."

**5. Design & Code Generation (1:30)**
- *Action:* Generate Design. Approve immediately. Generate Code.
- *Script:* "We move to Design, which uses our approved requirements as context. Let's approve it. Now, the Coding Agent writes the actual application source code based on that design."
- *Action:* Show the code viewer with syntax highlighting and Jev security checks.
- *Script:* "Notice Jev has scanned the code for architectural consistency and basic security. The code is treated purely as data—it is not executed here."

**6. Testing & Deployment (1:00)**
- *Action:* Generate Testing Analysis. Approve. Generate Deployment Plan. Approve.
- *Script:* "Next, the Testing Agent analyzes the code to generate test plans. Finally, the Deployment agent creates a CI/CD strategy."

**7. Final Approval (0:30)**
- *Action:* Click final project approval. Show completed dashboard.
- *Script:* "With the deployment strategy approved, the SDLC is complete. We've traversed idea to deployment documentation, governed entirely by human decisions, with AI doing the heavy lifting. Groq generated, Jev validated, and I governed."
