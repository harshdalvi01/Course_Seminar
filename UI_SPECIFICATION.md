# UI_SPECIFICATION.md

## AI-Native Software Engineering Platform

### UI/UX Design Specification

---

# 1. UI OBJECTIVE

The interface should look like a professional software engineering/productivity platform rather than a generic AI chatbot or a flashy AI-themed website.

The design should communicate:

- Software engineering
- Structured workflow
- Human control
- AI assistance
- Validation
- Traceability
- Progress through the SDLC

The UI must be:

- Clean
- Minimal
- Professional
- Subtle
- Consistent
- Easy to understand
- Easy to demonstrate during a seminar

The interface should prioritize usability over visual effects.

---

# 2. DESIGN PRINCIPLES

## 2.1 Subtle over flashy

Do NOT use:

- excessive gradients
- glowing AI effects
- animated backgrounds
- excessive rounded cards
- large decorative illustrations
- excessive shadows
- unnecessary animations
- excessive colors

The application should not look like a marketing landing page.

It should look like a real engineering tool.

---

## 2.2 Clear visual hierarchy

Every screen should make it immediately obvious:

1. Where am I?
2. Which project am I working on?
3. Which SDLC stage am I in?
4. What did the AI generate?
5. What did Jev validate?
6. What decision does the human need to make?

---

## 2.3 Consistency

Use the same visual language throughout:

- same spacing system
- same typography
- same buttons
- same cards
- same status indicators
- same stage navigation
- same review controls

Do not redesign components differently on different pages.

---

# 3. VISUAL STYLE

## Overall style

Professional SaaS / developer tool aesthetic.

Reference the visual language of serious productivity and developer applications, without copying any specific product.

Desired feeling:

> Calm, structured, technical, trustworthy.

---

# 4. COLOR SYSTEM

Use a restrained color palette.

## Primary

Use one subtle primary accent for:

- active navigation
- primary buttons
- selected stages
- links
- focus states

A muted blue or blue-indigo is recommended.

Do not use highly saturated neon colors.

---

## Neutral colors

Use:

- white / near-white page background
- slightly darker surfaces
- light borders
- dark gray primary text
- muted gray secondary text

Example conceptual palette:

```text
Background       #F8FAFC
Surface          #FFFFFF
Border           #E2E8F0
Primary Text     #0F172A
Secondary Text   #64748B
Primary Accent   #4F46E5
```
